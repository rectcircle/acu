macOS 15+ · Apple Silicon & Intel · MIT 开源

推荐：Homebrew 安装

已安装 Homebrew 时，在终端依次执行以下三条命令。确认信任 ACU 的发布产物后，再执行第三条命令。

Homebrew / zsh 
brew tap rectcircle/acu https://github.com/rectcircle/acu
brew install --cask rectcircle/acu/acu
/usr/bin/xattr -dr com.apple.quarantine /Applications/ACU.app

当前发布产物使用 ad-hoc 签名，未经 Apple 公证。确认信任源码与产物后，再允许应用运行。

手动安装（无需 Homebrew）

从 GitHub Releases 下载 macOS 通用 .dmg，打开后将 ACU.app 拖入 Applications。安装完成后，同样执行上面的第三条命令，再启动 ACU。

首次运行指南＋

  1. 允许 ACU 运行

    Homebrew 安装中已执行第三条命令的用户无需重复执行。手动安装后，仅在信任本项目时执行下方命令；它只移除 ACU 的 quarantine，不会全局关闭 Gatekeeper。

    /usr/bin/xattr -dr com.apple.quarantine /Applications/ACU.app

  2. 授予辅助功能权限

    系统设置 → 隐私与安全性 → 辅助功能，启用 ACU 并重启。仅当权限诊断提示无法监听输入时，才额外开启输入监控。

  3. 先体验 15 秒测试

    按住 Option 点击菜单栏图标，选择「测试模拟锁屏（15 秒自动退出）」。正式保护中，按 Enter 发起原生认证。

保护的边界，始终清楚。

ACU 是应用层模拟锁屏，不抵御进程终止、管理员权限或重启，不保证覆盖企业安全策略，也不能保证 Agent、电源与网络持续正常。检测到 macOS 真实锁屏后自动移除模拟保护，不会尝试解锁系统。
